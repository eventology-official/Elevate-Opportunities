## 💾 كيف تعمل البيانات؟

### ✅ التخزين المحلي (localStorage):
- جميع البيانات محفوظة في المتصفح مباشرة
- الحسابات، الفرص، التعليقات - كل شيء محلي
- لا حاجة لسيرفر أو قاعدة بيانات خارجية
- البيانات تبقى حتى لو أغلقت المتصفح

### ⚠️ ملاحظات مهمة:
- البيانات مرتبطة بالمتصفح الحالي فقط
- لو فتحت الموقع من متصفح آخر، ستبدأ بيانات جديدة
- لو حذفت بيانات المتصفح (Clear Cache)، ستضيع البيانات
- لنقل البيانات لجهاز آخر، انسخ localStorage يدوياً

## 🔧 استكشاف الأخطاء

### المشكلة: الموقع لا يفتح
**الحل:**
- تأكد أنك تفتح ملف `index.html` وليس أي ملف آخر
- جرب متصفح آخر (Chrome مفضل)
- تأكد أن JavaScript مفعل في المتصفح

### المشكلة: حساب المدير لا يعمل
**الحل:**
- استخدم: `admin` أو `admin@elevate.com`
- كلمة المرور: `elevate@admin#2026`
- رمز التحقق: `2026`
- لو ما اشتغل، احذف بيانات الموقع من المتصفح وأعد فتحه

### المشكلة: البيانات ضاعت
**الحل:**
- للأسف، بيانات localStorage تُحذف مع Clear Cache
- لحفظ البيانات، استخدم متصفحك بدون حذف الكاش
- أو انسخ localStorage يدوياً من Developer Tools

### المشكلة: الموقع بطيء
**الحل:**
- الموقع يعمل بسرعة لأنه محلي تماماً
- لو بطيء، جرب تحديث الصفحة (F5)
- أو أغلق التبويبات الأخرى

## 🎨 التخصيص

### تغيير بيانات المدير:
1. افتح ملف `db-sync.js`
2. ابحث عن السطر 20 تقريباً:
```javascript
username: "admin@elevate.com",
password: "elevate@admin#2026",
```
3. غير البيانات كما تريد
4. احفظ واعد فتح الموقع

### تغيير رمز التحقق (2FA):
1. افتح ملف `login.html`
2. ابحث عن:
```javascript
const CORRECT_CODE = '2026';
```
3. غير `2026` للرمز الذي تريده
4. احفظ الملف
